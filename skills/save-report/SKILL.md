**Usage:** /save-report [주제 또는 지시사항]

사용자가 요청한 주제 또는 현재 세션의 맥락을 바탕으로 보고서를 작성해 `~/Reports/`에 저장합니다.

## 무엇이 리포트인가

`~/Reports/`에는 **독립적으로 읽히는 완성 문서**만 들어갑니다. 배경부터 시작해서, 이 대화를 모르는 사람이 읽어도 이해할 수 있어야 합니다.

맥락에 기대는 짧은 기록("그 작업 중에 이런 판단을 했다")은 리포트가 아니라 로그입니다. 그건 `~/Reports/Logs/Claude Logs.md`나 해당 프로젝트의 `logs.md`로 갑니다. **이 스킬은 `Logs/` 아래에 쓰지 않습니다.**

큰 조사를 했다면 양쪽에 씁니다 — 본문은 리포트로, 로그에는 한 줄과 링크를.

## 작성 규칙

- 한국어로 작성합니다.
- **긴 글이므로 작성 전에 `~/.claude/writing-style.md`를 반드시 읽고 적용합니다.**
- **형식은 자유입니다.** 문서 성격에 맞는 구조를 고르세요 — 조사 보고서는 개요·타임라인·분석·결론이, 학습 정리는 개념·예제·요약이, 비교 분석은 기준·항목별 대조·판단이 어울립니다. 하나의 틀을 억지로 맞추지 않습니다.
- 사실과 의견을 구분해서 서술합니다.
- 필요하면 표, 코드 블록, 리스트를 씁니다.
- 수식은 LaTeX로 씁니다 — 인라인은 `$...$`, 블록은 `$$...$$` (예: `$E=mc^2$`, `$$\int \sec x\,dx = \ln|\sec x+\tan x|+C$$`). GitHub와 대부분의 마크다운 뷰어가 KaTeX로 렌더합니다.

## 고정 형식 — frontmatter + H1

본문 구조는 자유지만, 맨 위 두 가지는 고정입니다.

```markdown
---
title: macOS 침해사고 조사 보고서 — com.42346 백도어
date: 2026-07-29 16:37
type: research
summary: 크랙 설치로 유입된 원격 제어 백도어의 감염 경로·동작·피해 범위 분석
tags: [보안, macos, 침해사고]
---

# macOS 침해사고 조사 보고서 — com.42346 백도어

...본문...
```

| 필드 | 내용 |
| --- | --- |
| `title` | 한국어 제목. 본문 H1과 같은 값 |
| `date` | 작성 시각 `YYYY-MM-DD HH:MM` |
| `type` | `research` · `study` · `config` 중 하나 |
| `summary` | 한 줄 요약 |
| `tags` | 주제어 3~5개 |

**type 고르는 법**

- `research` — 조사·분석·비교. 무언가를 파헤친 결과
- `study` — 학습 정리. 교재나 강의 내용을 정리한 것
- `config` — 설정·규칙 문서. CLAUDE.md 개정안 같은 것

셋 어디에도 안 맞으면 사용자에게 새 값을 제안하고 합의합니다. 값을 늘리는 건 쉽지만, 잘게 나눈 걸 나중에 합치려면 기존 문서를 전부 고쳐야 합니다.

**tags 원칙** — 소문자로 통일하고, 새로 만들기 전에 `~/Reports/`의 기존 태그를 먼저 찾아 재사용합니다. 같은 개념에 두 표기를 쓰지 않습니다(`보안`과 `security` 중 하나만). 한국어·영어 혼용은 허용합니다. 문서당 3~5개를 넘기지 않습니다.

**H1은 본문 첫 줄에 그대로 유지합니다.** frontmatter를 숨기는 뷰어에서도 제목이 보여야 하기 때문입니다.

## 파일명

`YYYY-MM-DD_HH-MM-{title-slug}.md`

1. 제목에서 kebab-case slug를 만듭니다 (영문·숫자·하이픈만, 한글이면 음차 또는 영문 요약)
2. `date "+%Y-%m-%d_%H-%M"` 으로 현재 시각 prefix를 얻습니다
3. `~/Reports/{prefix}-{slug}.md` 경로에 Write 도구로 저장합니다
4. 같은 이름이 이미 있으면 `-2`, `-3` 식으로 suffix를 붙입니다

예: `2026-05-23_17-04-quarterly-roadmap-review.md`

**이 규약은 정렬과 검색을 위한 것입니다.** 파일 목록이 시간순으로 정렬되고, slug만 봐도 주제를 알 수 있습니다. frontmatter에 `date`와 `title`이 중복해서 들어가는 것은 문서가 파일명에 의존하지 않고 자립하게 하려는 것입니다 — 파일을 옮기거나 이름을 바꿔도 메타데이터가 살아남습니다.

## 저장 후

저장한 절대 경로를 한 줄로 알립니다.

사용자가 문서를 Claude 밖에서 열어볼 상황이면(인쇄·공유·다른 앱에서 편집) `~/Downloads/`에도 사본을 저장하고 채팅으로 함께 보냅니다. 원본은 `~/Reports/`에 남습니다.
