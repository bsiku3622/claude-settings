**Usage:** /brief

Summarize this session in 200 words or fewer. Write it as a system prompt — as if briefing the next session's Claude from scratch. Use this structure:

1. **Key Decisions** — what was decided and why
2. **Established Patterns** — conventions or patterns established during this session
3. **Next Steps** — what remains to be done

Be concrete. Omit pleasantries and filler. The output should be pasteable directly into the next session as context.

Respond in Korean.
